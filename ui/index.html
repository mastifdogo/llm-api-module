Gmail and iCloud need an app password (with 2-step verification on); Outlook.com and Microsoft 365 need IMAP enabled. The mailbox is opened read-only, so nothing is marked as read or moved. A dedicated folder or label (e.g. a filter that labels bills) keeps unrelated mail away from the model.
